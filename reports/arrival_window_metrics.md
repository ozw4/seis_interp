# 初動の前後で分けた評価（事後的・副指標）

既存の主指標 `mean_trace_snr_db` と `masked_trace_relative_mse` は、**「信号を再現できない」と
「信号の無いところにエネルギーを作る」を同じ数字に潰している**。本測定は各 trace を自分の初動時刻で
2つに割り、初動前の予測エネルギー（偽エネルギー）と初動後の再現性を別々に出す。

**追加の GPU は使っていない。** 全 run が採点済みの物理予測（`prediction.npy`）を保存しているので、
同じ予測・同じ target を窓付きで再集計しただけである。手法ごとに、再計算した trace 全体の SNR が
その run の保存済み採点値と一致することを検査しており、**7成果物すべてで最大差 0.0 dB** である。

## 窓の定義（波形を一切読まない）

初動 pick は target を読むので採点規律に反する。代わりに **`t < intercept + offset / velocity`** を
宣言し、測定した初動曲線の下に確実に収まる直線を使う。定数は**観測 trace だけ**（= model の入力）から
測り、余裕を付けて丸めた。

| dataset | 実測した初動 | 宣言した窓 | 窓長（最小 / 中央 / 最大） |
|---|---|---|---|
| FORGE | `0.314 s + offset/3865 m/s` | `0.22 s + offset/5500 m/s` | 55 / 95 / 158 sample |
| C3 | `0.375 s + offset/5227 m/s` | `0.25 s + offset/7000 m/s` | 44 / 59 / 69 sample |

検査: FORGE の参照 trace は全エネルギーの中央値 **0.19 %** しか窓内に持たない。窓が初動を飲み込んで
いれば桁違いに大きくなるので、窓が初動前であることの裏付けになる。
**C3 の参照は窓内が厳密に 0** である（合成データ）。したがって C3 では窓内の予測エネルギーは
**すべて偽エネルギー**であり、漏れの検出には理想的な条件になる。

## 読み方の制約（先に書く）

**ゼロ予測は偽エネルギー 0 で満点を取る。** profile NeRSI は FORGE で ≈0 dB・relMSE 1.0000 だが、
偽エネルギー指標では全手法中最良になる。偽エネルギー単独では順位を作れない。
**必ず (初動後 SNR, 偽エネルギー) の対として読む。**

## 結果1: 順位は変わらない

初動前は trace エネルギーの 0.19 % しかないので、初動後 SNR は trace 全体の SNR とほぼ同じである。
**窓で割っても手法の順位は1つも動かない。**

| 条件 | trace 全体 SNR | 初動後 SNR |
|---|---|---|
| FORGE shot50: ReGSI(076) > CCNet5D(076) > cINR(075) > DRR > POCS > NeRSI | 2.912 / 1.912 / 1.662 / 1.003 / 0.711 / 0.000 | 2.926 / 1.913 / 1.664 / 1.006 / 0.717 / 0.000 |

## 結果2: 偽エネルギーの出方は手法の種類で質的に違う

FORGE（実データ、初動前に環境ノイズがある）、clean_target、窓内の予測エネルギー ÷ 窓内の参照エネルギー:

| 手法 | 中央値（典型的な trace） | エネルギー重み（全体） |
|---|---:|---:|
| POCS | **1.154** | 0.041 |
| DRR | **0.412** | 0.024 |
| cINR (075) | 0.029 | **0.203** |
| ReGSI (069) | 0.012 | **0.285** |
| ReGSI (076) | 0.006 | **0.437** |
| CCNet5D (076) | 0.002 | 0.096 |
| CCNet5D (069) | 0.001 | 0.072 |
| profile NeRSI | 0.000 | 0.000 |

**中央値とエネルギー重みが逆の順序になる。** 古典手法は観測を射影・フィルタするので典型的な trace で
環境ノイズをほぼそのまま再現する（POCS 115 %）。学習型は典型的な trace では**ほぼ無音**（0.1–3 %）だが、
**少数の trace に大きなエネルギーを置く**ためエネルギー重みでは古典手法の 5–10 倍になる。
これは「ノイズを再現している」のではなく、**一部の trace に集中した漏れ**の符号である。

## 結果3: 漏れは最短オフセット帯に集中し、study_075 の弱点と一致する

FORGE shot50、オフセット五分位ごとの（窓内予測エネルギー ÷ 窓内参照エネルギー）:

| 手法 | 331 m | 642 m | 892 m | 1151 m | 1521 m |
|---|---:|---:|---:|---:|---:|
| ReGSI (076) | **0.437** | 0.034 | 0.024 | 0.017 | 0.023 |
| ReGSI (069) | **0.285** | 0.053 | 0.027 | 0.025 | 0.028 |
| cINR (075) | **0.203** | 0.013 | 0.034 | 0.078 | 0.068 |
| CCNet5D (076) | 0.096 | 0.004 | 0.013 | 0.041 | 0.019 |
| DRR (069) | 0.024 | 0.220 | 0.425 | **0.866** | 0.470 |
| POCS (069) | 0.042 | 0.461 | **1.745** | **3.797** | 1.172 |

学習型3手法はいずれも**最短オフセット帯で漏れが最大**（他帯の 3–20 倍）である。
[study_075](../studies/study_075_forge_random_shot50_gather_excluded/README.md) で最も弱かったのが
まさにこの帯（相関 0.356、relMSE 0.897、他帯は 0.548–0.621 / 0.662–0.750）であり、
**短オフセットの弱さは初動前への漏れと同じ場所にある**。

機構とも整合する。`models/trace_context_field.py` には時間シフト・moveout 補正が1つもなく、
ReGSI も `max_edge_time_shift_samples: 0` である。オフセットの違う近傍を時間シフトなしで重ねると、
最も近い近傍の初動より前にエネルギーが出る。moveout の曲率が最も大きいのは短オフセットなので、
漏れがそこに集中するのは予想どおりである。FORGE の共有前処理にある 500 m/s の canvas alignment は
粗い線形 moveout であって初動整列ではないため、近傍間の差分 moveout はほぼ未補正で残る。

逆に古典手法は中〜長オフセットで漏れが大きい（POCS は参照の 3.8 倍）。ただしそこは絶対エネルギーが
小さいので全体の順位には効かない。

## 結果4: 合成データでは誰も漏らさない

C3（参照が窓内で厳密に 0 なので、窓内の予測エネルギーは全部が偽）、窓内予測エネルギー ÷ trace 全体の
参照エネルギー:

| 手法 | 中央値 | エネルギー重み |
|---|---:|---:|
| DRR | 6.1e-5 | 1.13e-4 |
| cINR (071) | 2.2e-5 | 3.7e-5 |
| ReGSI (067) | 2.0e-6 | 3.0e-6 |
| POCS (067) | 0.0 | 4.0e-6 |
| CCNet5D (067) | 0.0 | 1.6e-7 |
| profile NeRSI | 0.0 | 1.4e-8 |

**最大でも trace エネルギーの 0.011 %** であり、合成データでは漏れは実質的に存在しない。
偽エネルギーが問題になるのは実データのノイズ条件下だけである。

## 位置づけと留保

- **事後的・開示付きの副指標**である。study の採点結果を見た後に追加したので、選択には遡って使えない
  （選択は validation relMSE で確定済み）。主指標・順位・採否はどれも変更していない。
- 窓の定数は観測 trace から測った宣言値であり、初動 pick ではない。pick 版（凍結 pick を hash 固定）は
  別の感度解析になる。
- 漏れが「近傍オフセット差」に起因するという説明は機構と整合するが、**本測定は因果を検証していない**。
  検証には trace ごとの近傍オフセット差と偽エネルギーの対応を測る必要があり、別作業とする。
- 1 mask・1 model seed（shot50）／ seed 7321 のみ（共通 grid）の記述的測定で、CI も多重比較補正もない。
