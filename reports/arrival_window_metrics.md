# 初動の前後で分けた評価（事後的・副指標）

既存の主指標 `mean_trace_snr_db` と `masked_trace_relative_mse` は、**「信号を再現できない」と
「信号の無いところにエネルギーを作る」を同じ数字に潰している**。本測定は各 trace を自分の初動時刻で
2つに割り、**初動前に手法が出したノイズ振幅**と、初動後の再現性を別々に出す。

主指標は**窓内の予測 RMS 振幅の中央値**で、同じ trace の**本当のノイズ振幅**と並べて読む。
データの単位のままで、参照が無音でも定義できる（比率は定義できない）。

> **中央値を使う理由。** trace 振幅は桁で散らばる。FORGE では参照自身の初動前 RMS が
> **平均 / 中央値 = 73 倍**である。平均を取ると少数の大振幅 trace（近オフセット）だけが数字を決め、
> **ギャザー図の見た目と逆の順序になる**。本報告の初版は平均を主指標にしており、その順序は
> 図の印象と矛盾していた。中央値に改め、平均は歪みの診断として併記する。

**追加の GPU は使っていない。** 全 run が採点済みの物理予測（`prediction.npy`）を保存しているので、
同じ予測・同じ target を窓付きで再集計しただけである。手法ごとに、再計算した trace 全体の SNR が
その run の保存済み採点値と一致することを検査しており、**20 手法すべてで最大差 0.0 dB** である。

## 窓の定義（波形を一切読まない）

初動 pick は target を読むので採点規律に反する。代わりに **`t < intercept + offset / velocity`** を
宣言し、測定した初動曲線の下に確実に収まる直線を使う。定数は**観測 trace だけ**（= model の入力）から
測り、余裕を付けて丸めた。

| dataset | 実測した初動 | 宣言した窓 | 窓長（最小 / 中央 / 最大） |
|---|---|---|---|
| FORGE | `0.314 s + offset/3865 m/s` | `0.22 s + offset/5500 m/s` | 55 / 95 / 158 sample |
| C3 | `0.375 s + offset/5227 m/s` | `0.25 s + offset/7000 m/s` | 44 / 59 / 69 sample |

検査: FORGE の参照 trace は全エネルギーの中央値 0.19 % しか窓内に持たない。窓が初動を飲み込んで
いれば桁違いに大きくなるので、窓が初動前であることの裏付けになる。
**C3 の参照は窓内が厳密に 0** である（合成データ）。したがって C3 では窓内の予測振幅は
**すべて作り出した偽信号**であり、漏れの検出には理想的な条件になる。

## 読み方の制約（先に書く）

**ゼロ予測は偽振幅 0 で満点を取る。** profile NeRSI は FORGE で ≈0 dB・relMSE 1.0000 だが、
偽振幅では全手法中最良になる。偽振幅単独では順位を作れない。
**必ず (初動後 SNR, 偽振幅) の対として読む。**

## 結果1: 順位は変わらない

初動前は trace エネルギーの 0.19 % しかないので、初動後 SNR は trace 全体の SNR とほぼ同じである。
**窓で割っても手法の順位は1つも動かない。**

| 条件 | trace 全体 SNR | 初動後 SNR |
|---|---|---|
| FORGE shot50: ReGSI(076) > CCNet5D(076) > cINR(075) > DRR > POCS > NeRSI | 2.912 / 1.912 / 1.662 / 1.003 / 0.711 / 0.000 | 2.926 / 1.913 / 1.664 / 1.006 / 0.717 / 0.000 |

## 結果2: 実データでは古典手法だけがノイズを再現し、学習型は初動前を消している

FORGE shot50、clean_target、窓内 RMS 振幅の**中央値**（物理単位）。
**本物のノイズ振幅は全手法共通で 3.3435e-05**（同じ trace を見ているため）。

| 手法 | 出した振幅（中央値） | 本物に対する比（比の中央値） | エネルギー比の中央値 | 初動後 SNR |
|---|---:|---:|---:|---:|
| POCS (069) | 5.2772e-05 | **107 %** | 1.1544 | 0.717 |
| **本物のノイズ** | **3.3435e-05** | **100 %** | **1.0000** | — |
| DRR (069) | 2.6587e-05 | 64 % | 0.4117 | 1.006 |
| cINR (075) | 6.6905e-06 | **17 %** | 0.02924 | 1.664 |
| ReGSI (069) | 3.6378e-06 | 11 % | 0.01217 | 2.581 |
| ReGSI (076) | 2.8828e-06 | 7.4 % | 0.005542 | 2.926 |
| CCNet5D (076) | 1.8042e-06 | 4.2 % | 0.001761 | 1.913 |
| CCNet5D (069) | 1.1026e-06 | 2.7 % | 0.000703 | 1.214 |
| profile NeRSI (069) | 1.1633e-08 | 0.02 % | 5.2e-08 | 0.000 |

「本物に対する比」は **trace ごとの比 `予測 RMS / 参照 RMS` の中央値**である（中央値どうしの比ではない。
両者は POCS で 1.07 対 1.58 と数十 % 違う）。最終列はその**エネルギー形**で、振幅比の2乗に一致する。

**これはギャザー図の見た目と一致する。** POCS・DRR のパネルは初動前も雑音で埋まり、
学習型のパネルは初動前が白い。古典手法は観測を射影・フィルタするのでノイズをそのまま通し、
学習型は**初動前を消す方向に学習している**（本物の 3–20 %）。

共通 grid（random-trace 70 %、本物 3.3382e-05）でも同じ構図である（比の中央値）:
DRR 107 % / POCS 96 % / **cINR 14 %** / ReGSI 9.3 % / CCNet5D 8.5 % / profile NeRSI 4.1 %。

**学習型3手法の中では cINR が一貫して最も多く出す**（FORGE shot50 で ReGSI(076) の 2.3 倍、
CCNet5D(076) の 4.1 倍。共通 grid でも ReGSI の 1.5 倍、CCNet5D の 1.7 倍）。

参考（エネルギー重み、`pooled_pre_excess_ratio`）: 同じ量をエネルギー総和の比で取ると
**順序が逆転する** — ReGSI(076) 0.437 / ReGSI(069) 0.285 / cINR 0.203 / CCNet5D(076) 0.096 /
CCNet5D(069) 0.072 / POCS 0.041 / DRR 0.024 / NeRSI 0.000。近オフセット trace の絶対振幅が
他帯の 400 倍あるためで、平均と同じ理由である。**この列は単独で引用しない。**

## 結果3: 合成 C3 では「出した振幅」がそのまま偽信号

C3 は窓内の参照が厳密に 0 なので、窓内の予測振幅は全部が偽である（中央値）。

| 手法 | 出した振幅 | trace RMS 比 | 初動後 SNR |
|---|---:|---:|---:|
| DRR (067) | 0.18677 | **2.08 %** | 17.73 |
| **cINR (071)** | **0.11390** | **1.26 %** | 14.08 |
| ReGSI (067) | 0.03009 | 0.33 % | 20.04 |
| CCNet5D (067) | 0.01273 | 0.14 % | 18.89 |
| profile NeRSI (067) | 0.01023 | 0.11 % | 12.56 |
| POCS (067) | 0.00028 | 0.003 % | 13.83 |

**POCS の FORGE での高い値は「偽信号」ではなく「ノイズの忠実な再現」である。** 再現すべきものが
何も無い C3 では POCS はほぼ何も出さない（0.003 %、全手法中最小）。一方 **cINR は C3 でも 2 位
（1.26 %）で、ReGSI の 3.8 倍・CCNet5D の 9.0 倍**である。参照が無音なのでこれは曖昧さなく
**作ってしまった信号**であり、FORGE と C3 の両方で cINR が学習型中最大という結論は一致する。

機構とも整合する。`models/trace_context_field.py` には時間シフト・moveout 補正が1つもなく、
ReGSI も `max_edge_time_shift_samples: 0` である。オフセットの違う近傍を時間シフトなしで重ねると、
最も近い近傍の初動より前にエネルギーが出る。FORGE の共有前処理にある 500 m/s の canvas alignment は
粗い線形 moveout であって初動整列ではないため、近傍間の差分 moveout はほぼ未補正で残る。
DRR が C3 で最大なのは、ランク縮小が窓外の信号を窓内へにじませるためと整合する。

## 位置づけと留保

- **事後的・開示付きの副指標**である。study の採点結果を見た後に追加したので、選択には遡って使えない
  （選択は validation relMSE で確定済み）。主指標・順位・採否はどれも変更していない。
- 窓の定数は観測 trace から測った宣言値であり、初動 pick ではない。pick 版（凍結 pick を hash 固定）は
  別の感度解析になる。
- **平均とエネルギー重みは単独で引用しない。** 近オフセット trace が 400 倍の絶対振幅を持つため、
  どちらも図の見た目と逆の順序（ReGSI 最大、POCS 下位）を与える。`summary.csv` には
  `mean_pre_prediction_rms` と `pooled_pre_excess_ratio` を診断として残してある。
- 比は **trace ごとに取ってから中央値**にする。中央値どうしを割ると POCS で 1.07 が 1.58 になる。
- 偽振幅が「近傍オフセット差」に起因するという説明は機構と整合するが、**本測定は因果を検証していない**。
  検証には trace ごとの近傍オフセット差と偽振幅の対応を測る必要があり、別作業とする。
- 1 mask・1 model seed（shot50）／ seed 7321 のみ（共通 grid）の記述的測定で、CI も多重比較補正もない。
