# 初動の前後で分けた評価（事後的・副指標）

既存の主指標 `mean_trace_snr_db` と `masked_trace_relative_mse` は、**「信号を再現できない」と
「信号の無いところにエネルギーを作る」を同じ数字に潰している**。本測定は各 trace を自分の初動時刻で
2つに割り、**初動前に手法が出したノイズ振幅**と、初動後の再現性を別々に出す。

判定は**窓内 relMSE の中央値を 1.0（= ゼロ予測の値）と比べて**行う。環境ノイズは trace ごとに
別実現なので予測できず、二乗誤差の下では 0 を出すのが最適だからである。
**参照が無音の合成データでのみ**、出した振幅そのものが偽信号の量になる。

> **中央値を使う理由。** trace 振幅は桁で散らばる。FORGE では参照自身の初動前 RMS が
> **平均 / 中央値 = 73 倍**である。平均を取ると少数の大振幅 trace（近オフセット）だけが数字を決め、
> **ギャザー図の見た目と逆の順序になる**。本報告の初版は平均を主指標にしており、その順序は
> 図の印象と矛盾していた。中央値に改め、平均は歪みの診断として併記する。

**追加の GPU は使っていない。** 全 run が採点済みの物理予測（`prediction.npy`）を保存しているので、
同じ予測・同じ target を窓付きで再集計しただけである。手法ごとに、再計算した trace 全体の SNR が
その run の保存済み採点値と一致することを検査しており、**20 手法すべてで最大差 0.0 dB** である。

## 窓の定義（波形を一切読まない）

初動 pick は target を読むので採点規律に反する。代わりに **`t < intercept + offset / velocity`** を
宣言し、測定した初動曲線の下に確実に収まる直線を使う。定数は**観測 trace だけ**（= model の入力）から
測り、余裕を付けて丸めた。

| dataset | 実測した初動 | 宣言した窓 | 窓長（最小 / 中央 / 最大） |
|---|---|---|---|
| FORGE | `0.314 s + offset/3865 m/s` | `0.22 s + offset/5500 m/s` | 55 / 95 / 158 sample |
| C3 | `0.375 s + offset/5227 m/s` | `0.25 s + offset/7000 m/s` | 44 / 59 / 69 sample |

検査: FORGE の参照 trace は全エネルギーの中央値 0.19 % しか窓内に持たない。窓が初動を飲み込んで
いれば桁違いに大きくなるので、窓が初動前であることの裏付けになる。
**C3 の参照は窓内が厳密に 0** である（合成データ）。したがって C3 では窓内の予測振幅は
**すべて作り出した偽信号**であり、漏れの検出には理想的な条件になる。

## 読み方の制約（先に書く）

**ゼロ予測は初動前では最適値そのものである。** profile NeRSI は FORGE で ≈0 dB・relMSE 1.0000 の
縮退した手法だが、初動前だけを見れば窓内 relMSE ちょうど 1.0 で、CCNet5D と区別できない。
初動前の指標は単独では順位を作れない。**必ず (初動後 SNR, 窓内 relMSE) の対として読む。**

## 結果1: 順位は変わらない

初動前は trace エネルギーの 0.19 % しかないので、初動後 SNR は trace 全体の SNR とほぼ同じである。
**窓で割っても手法の順位は1つも動かない。**

| 条件 | trace 全体 SNR | 初動後 SNR |
|---|---|---|
| FORGE shot50: ReGSI(076) > CCNet5D(076) > cINR(075) > DRR > POCS > NeRSI | 2.912 / 1.912 / 1.662 / 1.003 / 0.711 / 0.000 | 2.926 / 1.913 / 1.664 / 1.006 / 0.717 / 0.000 |

## 結果2: 初動前は「予測しない」のが正解で、古典手法はそこで損をしている

**環境ノイズは trace ごとに別実現なので予測できない。** 二乗誤差の下では、予測不能な零平均成分の
最適推定は **0** である。したがって初動前の窓は「振幅をどれだけ出したか」ではなく、
**窓内 relMSE を 1.0 と比べて**判定する。

- **= 1.0** — ゼロ予測と同じ。予測不能な部分に対する最適値。
- **< 1.0** — 本当に予測可能な成分（コヒーレントノイズなど）を見つけている。
- **> 1.0** — 無相関な実現を注入して悪化させている。分散の等しい独立実現を入れると **2.0** になる。

FORGE shot50、clean_target、窓内 relMSE の中央値:

| 手法 | 窓内 relMSE | 判定 | 出した振幅の比 | 初動後 SNR |
|---|---:|---|---:|---:|
| ReGSI (069) | **0.9951** | ゼロ予測に勝つ | 0.110 | 2.581 |
| ReGSI (076) | **0.9969** | ゼロ予測に勝つ | 0.074 | 2.926 |
| profile NeRSI (069) | 1.0000 | ゼロ予測そのもの | 0.0002 | 0.000 |
| CCNet5D (069) | 1.0001 | 最適と区別できない | 0.027 | 1.214 |
| CCNet5D (076) | 1.0004 | 最適と区別できない | 0.042 | 1.913 |
| cINR (075) | 1.0187 | わずかに注入 | 0.171 | 1.664 |
| DRR (069) | 1.3746 | 注入して悪化 | 0.642 | 1.006 |
| POCS (069) | **2.0989** | **独立実現の注入（理論値 2.0）** | 1.074 | 0.717 |

**POCS の 2.099 は理論値 2.0 とほぼ一致する。** 近傍 trace のノイズをそのまま通しており、
それは対象 trace 自身のノイズと無相関なので、**ゼロを出した場合の 2 倍の誤差**になる。
DRR も 1.375 で同じ向きである。「ノイズを忠実に再現している」のではなく、**再現できないものを
再現しようとして損をしている**。

**学習型が初動前をほぼ無音にするのは正しい挙動である。** CCNet5D は最適値と区別できず（1.0001–1.0004）、
**ReGSI だけが 1 を下回り**（0.995–0.997）、予測可能な成分をわずかに拾っている。
cINR は学習型で唯一 1 を超える（1.019）。

共通 grid でも同じ構図である（窓内 relMSE 中央値）:
ReGSI 0.993 / profile NeRSI 1.002 / CCNet5D 1.003 / cINR 1.016 / POCS 1.860 / DRR 2.113。

> **初版の訂正。** 本報告の初版は「古典手法だけがノイズを再現し、学習型は初動前を消しすぎている」と
> 書き、振幅比が 100 % に近いほど忠実だと扱った。**これは誤りである。** ノイズは予測不能なので
> 100 % を目指すこと自体が誤りで、上表のとおり振幅を合わせた手法ほど誤差が大きい。
> 振幅比は**参照が無音の場合（C3）にのみ**良否を判定でき、実データでは窓内 relMSE で判定する。


## 結果2b: 3つの振る舞いに分かれる（まとめ方の妥当性）

窓内 relMSE・振幅比・窓内相関を併記すると、手法は3群に分かれる。FORGE shot50、clean_target、中央値:

| 手法 | 窓内 relMSE | 振幅比 | 窓内相関 | 前半 / 後半 | 振る舞い |
|---|---:|---:|---:|---:|---|
| ReGSI (069) | 0.9951 | 0.110 | **0.0953** | 0.092 / 0.109 | 大半を 0 にし、一部を当てている |
| ReGSI (076) | 0.9969 | 0.074 | **0.0761** | 0.066 / 0.090 | 同上 |
| CCNet5D (069) | 1.0001 | 0.027 | 0.0132 | 0.017 / 0.015 | 実質 0 を出す |
| CCNet5D (076) | 1.0004 | 0.042 | 0.0066 | 0.011 / 0.008 | 実質 0 を出す |
| cINR (075) | 1.0187 | 0.171 | 0.0286 | 0.027 / 0.037 | 弱く注入している |
| DRR (069) | 1.3746 | 0.642 | 0.0270 | 0.038 / 0.026 | 注入している |
| POCS (069) | 2.0989 | 1.074 | 0.0335 | 0.037 / 0.034 | 強く注入している |
| profile NeRSI (069) | 1.0000 | 0.0002 | 0.0122 | 0.014 / 0.013 | 文字どおり 0（縮退手法） |

**(A) 注入群（POCS・DRR、弱い形で cINR）。** 振幅比 α の無相関な別実現を出すと窓内 relMSE は
`1 + α²` になる。実測との一致は良い: POCS α=1.074 → 予測 2.154 / 実測 2.099、
DRR α=0.642 → 1.412 / 1.375、cINR α=0.171 → 1.029 / 1.019。窓内相関はいずれも 0.027–0.034 で
ほぼ無相関である。**「この trace のノイズとは無相関な、別 trace 由来のノイズを通している」**のが
正確な記述で、「コピー」はその略称として妥当である。cINR は同じ符号だが POCS の約 100 分の1 の強さで、
学習型では唯一 1 を超える。

**(B) ゼロ群（CCNet5D）。** 文字どおり 0 ではなく本物のノイズ振幅の 2.7–4.2 % を出すが、
窓内 relMSE はゼロ予測と区別できず（1.0001–1.0004）、窓内相関も 0.007–0.013 でほぼ無相関である。
**「実質 0 にする」で妥当。** ただし**ゼロ予測より良くはない**（わずかに 1 を超える側）。

**(C) 一部予測群（ReGSI）。** 振幅比 0.074–0.110 なので大半は 0 にしており、かつ窓内 relMSE が
**3つの独立な run すべてで 1 を下回る**（0.9951 / 0.9969、共通 grid 0.9930）。他のどの手法も
1.0000 を下回らない。窓内相関 0.076–0.095 は他手法の 2–7 倍である。
**「大半を 0 にし、一部を予測している」で妥当。**

**窓端に初動が漏れている可能性は否定できる。** もし窓末尾が初動を拾っているなら相関は後半に集中する
はずだが、ReGSI の前半 0.066–0.092 は後半 0.090–0.109 と同程度で、比は 1.19–1.36 にとどまる。
相関は窓全体に広がっており、端の効果ではない。

**ただし効果は小さい。** 誤差の改善は 0.3–0.5 %、相関 0.076–0.095（説明できる分散は 0.6–0.9 %）である。
**それがコヒーレントノイズなのかは本測定では切り分けていない**（trace 単位の振幅・トレンド成分でも
同じ符号が出る）。

**使ってはいけない統計:** 「ゼロ予測に勝つ trace の割合」は符号だけを見るので、振幅が無限小でも
わずかな符号相関があれば 50 % を超える。実際 **profile NeRSI（縮退した実質ゼロ予測）が 57.4 % で
ReGSI の 55.8 % を上回る**。この統計で (B) と (C) を分けてはならない。


## 結果2c: 窓を数サンプル早める感度解析

窓の余裕が最も小さいのは近オフセット（約 0.09 s）なので、そこに初動が漏れていないかを、
**窓を宣言位置より 6 サンプル・15 サンプル（24 ms・60 ms）早めて**確かめた。
対象は最近接オフセット五分位（7–510 m、4,901 trace）。窓長は shift 0 で 55–78 sample、
−15 でも 40–63 sample で、最小要件 16 sample を十分上回る。

| 手法 | 平均 0 / −6 / −15 | 中央値 0 / −6 / −15 | pooled 0 / −6 / −15 | p99 0 / −15 |
|---|---|---|---|---|
| POCS (069) | 2.759 / 3.447 / **4.878** | 1.553 / 1.607 / 1.688 | 1.039 / 1.041 / 1.051 | 25.5 / **58.2** |
| DRR (069) | 1.680 / 1.903 / **2.400** | 1.211 / 1.240 / 1.275 | 1.023 / 1.023 / 1.020 | 9.5 / **22.1** |
| cINR (075) | 1.078 / 1.097 / 1.175 | 1.0078 / 1.0068 / 1.0070 | 1.174 / 1.167 / 1.138 | 2.6 / 4.1 |
| CCNet5D (076) | 1.081 / 1.093 / 1.167 | 1.0033 / 1.0023 / 1.0011 | 1.100 / 1.090 / 1.074 | 2.5 / 3.9 |
| CCNet5D (069) | 1.055 / 1.063 / 1.132 | 1.0025 / 1.0017 / 1.0008 | 1.070 / 1.065 / 1.063 | 2.0 / 3.7 |
| ReGSI (069) | 0.991 / 0.994 / **1.004** | 0.9944 / 0.9949 / 0.9956 | 1.149 / 1.129 / 1.098 | 1.86 / 1.90 |
| ReGSI (076) | 0.977 / 0.987 / **1.004** | 0.9962 / 0.9971 / 0.9972 | 1.281 / 1.269 / 1.299 | 1.92 / 1.85 |
| profile NeRSI (069) | 1.0000 / 1.0000 / 1.0000 | 1.0000 | 1.0000 | 1.0001 / 1.0002 |

**平均では「大きくならない」ことを確認できない。** 近オフセットの平均は窓を早めるほど増え、
POCS は +77 %（2.759 → 4.878）、DRR は +43 % になる。**中央値と pooled では確認できる**:
中央値の変化は POCS で 0.135、学習型では 0.002 以下、pooled の変化はすべて 0.05 以下である。

**原因は窓の汚染ではなく分布の裾である。** p99 が POCS 25.5 → 58.2、DRR 9.5 → 22.1 と倍増する一方、
中央値と pooled は動かない。もし shift 0 の窓が初動を拾っていたなら、窓を早めると
**信号を当てている手法の誤差は小さくなる**はずで、中央値と pooled も動くはずだが、どちらも動かない。
窓を早めると参照の窓内エネルギーが下がり、一部の trace で比が跳ね上がるために平均だけが動く。

**三群の結論はどの shift でも変わらない**（中央値）: POCS・DRR は 1 を大きく超え、CCNet5D は 1 と
区別できず、ReGSI は 1 を下回り、cINR はわずかに 1 を超える。

**ただし ReGSI の「1 を下回る」は平均では shift 依存である。** 近オフセットの平均は
shift 0 で 0.977–0.991 だが **−15 サンプルで 1.004 と符号が反転する**。中央値では全 shift で
0.9944–0.9972 と一貫して 1 未満である。結果2b の (C) は**中央値での主張**であり、
平均で主張してはならない。

## 結果3: 合成 C3 では「出した振幅」がそのまま偽信号

C3 は窓内の参照が厳密に 0 なので、窓内の予測振幅は全部が偽である（中央値）。

| 手法 | 出した振幅 | trace RMS 比 | 初動後 SNR |
|---|---:|---:|---:|
| DRR (067) | 0.18677 | **2.08 %** | 17.73 |
| **cINR (071)** | **0.11390** | **1.26 %** | 14.08 |
| ReGSI (067) | 0.03009 | 0.33 % | 20.04 |
| CCNet5D (067) | 0.01273 | 0.14 % | 18.89 |
| profile NeRSI (067) | 0.01023 | 0.11 % | 12.56 |
| POCS (067) | 0.00028 | 0.003 % | 13.83 |

**POCS が C3 でほぼ何も出さない**（0.003 %、全手法中最小）のは、C3 の初動前に通すべきノイズが
無いからである。POCS は観測を射影するだけなので、入力に無いものは作らない。FORGE で振幅が大きい
のはノイズを通した結果であって捏造ではないが、結果2のとおり**それは誤差を 2 倍にしている**。

一方 **cINR は C3 でも 2 位（1.26 %）で、ReGSI の 3.8 倍・CCNet5D の 9.0 倍**である。
参照が無音なのでこれは曖昧さなく**作ってしまった信号**であり、FORGE で学習型中唯一
窓内 relMSE が 1 を超える（1.019）ことと一致する。**両 dataset とも cINR が学習型中最大**である。

機構とも整合する。`models/trace_context_field.py` には時間シフト・moveout 補正が1つもなく、
ReGSI も `max_edge_time_shift_samples: 0` である。オフセットの違う近傍を時間シフトなしで重ねると、
最も近い近傍の初動より前にエネルギーが出る。FORGE の共有前処理にある 500 m/s の canvas alignment は
粗い線形 moveout であって初動整列ではないため、近傍間の差分 moveout はほぼ未補正で残る。
DRR が C3 で最大なのは、ランク縮小が窓外の信号を窓内へにじませるためと整合する。

## 位置づけと留保

- **事後的・開示付きの副指標**である。study の採点結果を見た後に追加したので、選択には遡って使えない
  （選択は validation relMSE で確定済み）。主指標・順位・採否はどれも変更していない。
- 窓の定数は観測 trace から測った宣言値であり、初動 pick ではない。pick 版（凍結 pick を hash 固定）は
  別の感度解析になる。窓位置そのものの感度は結果2c で確認済みで、`--window-shift-samples` で再現できる。
- **実データで振幅比を良否の指標にしない。** ノイズは予測不能なので 100 % を目指すこと自体が誤りで、
  振幅を合わせた手法ほど窓内 relMSE が悪い。振幅が良否を決めるのは参照が無音の C3 だけである。
- **平均とエネルギー重みは単独で引用しない。** 近オフセット trace が 400 倍の絶対振幅を持つため、
  どちらも図の見た目と逆の順序を与える。`summary.csv` には診断として残してある。
- 比は **trace ごとに取ってから中央値**にする。中央値どうしを割ると POCS で 1.07 が 1.58 になる。
- 窓内 relMSE が 1 を下回るのは ReGSI だけ（0.993–0.997）で、差は 0.3–0.7 % と小さい。
  これが本当にコヒーレントノイズの予測なのかは本測定では切り分けていない。
- 偽振幅が「近傍オフセット差」に起因するという説明は機構と整合するが、**本測定は因果を検証していない**。
  検証には trace ごとの近傍オフセット差と偽振幅の対応を測る必要があり、別作業とする。
- 1 mask・1 model seed（shot50）／ seed 7321 のみ（共通 grid）の記述的測定で、CI も多重比較補正もない。
