# 初動の前後で分けた評価（事後的・副指標）

既存の主指標 `mean_trace_snr_db` と `masked_trace_relative_mse` は、**「信号を再現できない」と
「信号の無いところにエネルギーを作る」を同じ数字に潰している**。本測定は各 trace を自分の初動時刻で
2つに割り、**初動前に手法が作ってしまったノイズ振幅**と、初動後の再現性を別々に出す。

主指標は**窓内の予測 RMS 振幅を、重み付けなしで trace 平均したもの**である。データの単位のままで、
参照が無音でも定義でき、同じ trace の**本当のノイズ振幅**と並べて読める。

**追加の GPU は使っていない。** 全 run が採点済みの物理予測（`prediction.npy`）を保存しているので、
同じ予測・同じ target を窓付きで再集計しただけである。手法ごとに、再計算した trace 全体の SNR が
その run の保存済み採点値と一致することを検査しており、**20 手法すべてで最大差 0.0 dB** である。

## 窓の定義（波形を一切読まない）

初動 pick は target を読むので採点規律に反する。代わりに **`t < intercept + offset / velocity`** を
宣言し、測定した初動曲線の下に確実に収まる直線を使う。定数は**観測 trace だけ**（= model の入力）から
測り、余裕を付けて丸めた。

| dataset | 実測した初動 | 宣言した窓 | 窓長（最小 / 中央 / 最大） |
|---|---|---|---|
| FORGE | `0.314 s + offset/3865 m/s` | `0.22 s + offset/5500 m/s` | 55 / 95 / 158 sample |
| C3 | `0.375 s + offset/5227 m/s` | `0.25 s + offset/7000 m/s` | 44 / 59 / 69 sample |

検査: FORGE の参照 trace は全エネルギーの中央値 0.19 % しか窓内に持たない。窓が初動を飲み込んで
いれば桁違いに大きくなるので、窓が初動前であることの裏付けになる。
**C3 の参照は窓内が厳密に 0** である（合成データ）。したがって C3 では窓内の予測振幅は
**すべて作り出した偽信号**であり、漏れの検出には理想的な条件になる。

## 読み方の制約（先に書く）

**ゼロ予測は偽振幅 0 で満点を取る。** profile NeRSI は FORGE で ≈0 dB・relMSE 1.0000 だが、
偽振幅では全手法中最良になる。偽振幅単独では順位を作れない。
**必ず (初動後 SNR, 偽振幅) の対として読む。**

## 結果1: 順位は変わらない

初動前は trace エネルギーの 0.19 % しかないので、初動後 SNR は trace 全体の SNR とほぼ同じである。
**窓で割っても手法の順位は1つも動かない。**

| 条件 | trace 全体 SNR | 初動後 SNR |
|---|---|---|
| FORGE shot50: ReGSI(076) > CCNet5D(076) > cINR(075) > DRR > POCS > NeRSI | 2.912 / 1.912 / 1.662 / 1.003 / 0.711 / 0.000 | 2.926 / 1.913 / 1.664 / 1.006 / 0.717 / 0.000 |

## 結果2: どの手法も本当のノイズより小さい振幅しか出していない

FORGE shot50、clean_target、窓内 RMS 振幅の trace 平均（重み付けなし、物理単位）。
**本当のノイズ振幅は全手法共通で 0.0024251**（同じ trace を見ているため）。

| 手法 | 作った振幅 | 本物に対する比 | 初動後 SNR |
|---|---:|---:|---:|
| ReGSI (076) | 0.0014146 | **58 %** | 2.926 |
| ReGSI (069) | 0.0011355 | 47 % | 2.581 |
| cINR (075) | 0.0009835 | 41 % | 1.664 |
| POCS (069) | 0.0008343 | 34 % | 0.717 |
| CCNet5D (076) | 0.0007563 | 31 % | 1.913 |
| CCNet5D (069) | 0.0006348 | 26 % | 1.214 |
| DRR (069) | 0.0005686 | 23 % | 1.006 |
| profile NeRSI (069) | 0.0000001 | 0.004 % | 0.000 |

**どの手法も本当の初動前ノイズを過小にしか出していない**（最大でも 58 %）。
学習型の上位2つ（ReGSI・cINR）が最も多く出し、古典手法より多い。
共通 grid（random-trace 70 %）でも同じ順序である: ReGSI 0.0014469・cINR 0.0014850 が上位で、
POCS 0.0007650・DRR 0.0010146 がその下、profile NeRSI 0.0003566（本物は 0.0024941）。

**この平均は大振幅 trace（近オフセット）が支配する。** trace ごとに自分の RMS で割ってから平均すると
順序が変わる（下記）。同じ測定の2つの見方であり、どちらも正しい。

## 結果3: trace 自身の振幅で割ると、古典手法だけがノイズを再現している

FORGE shot50、窓内 RMS ÷ その trace 全体の RMS、trace 平均（重み付けなし）:

| 手法 | 331 m | 642 m | 892 m | 1151 m | 1521 m |
|---|---:|---:|---:|---:|---:|
| **本物のノイズ** | **0.403** | **0.182** | **0.108** | **0.098** | **0.185** |
| POCS (069) | 0.267 | 0.150 | 0.156 | 0.158 | 0.159 |
| DRR (069) | 0.177 | 0.096 | 0.080 | 0.082 | 0.105 |
| ReGSI (076) | 0.143 | 0.017 | 0.011 | 0.010 | 0.020 |
| cINR (075) | 0.109 | 0.023 | 0.021 | 0.025 | 0.043 |
| CCNet5D (076) | 0.086 | 0.008 | 0.010 | 0.010 | 0.013 |
| profile NeRSI (069) | 0.00004 | 0.00006 | 0.00008 | 0.00013 | 0.00021 |

**古典手法は本物のノイズを概ね再現する**（POCS は本物の 66–160 %）。観測を射影・フィルタする手法なので
当然である。**学習型は本物の 6–35 % しか出さない。** 近オフセットでは本物の 21–35 % だが、
中〜長オフセットでは 6–23 % に落ちる。つまり学習型は**初動前を「無音に寄せて」出力しており**、
その寄せ方は長オフセットほど強い。

絶対振幅（結果2）で学習型が上位に来るのは、近オフセット帯の絶対振幅が他帯の 400 倍あり、
平均がその帯に支配されるためである。**近オフセットでだけ学習型は相対的にも多く出している。**

## 結果4: 合成 C3 では「作った振幅」がそのまま偽信号

C3 は窓内の参照が厳密に 0 なので、窓内の予測振幅は全部が偽である。

| 手法 | 作った振幅（RMS 平均） | trace RMS 比 | 初動後 SNR |
|---|---:|---:|---:|
| DRR (067) | 0.2255 | **2.41 %** | 17.73 |
| **cINR (071)** | **0.1299** | **1.43 %** | 14.08 |
| ReGSI (067) | 0.0351 | 0.38 % | 20.04 |
| POCS (067) | 0.0217 | 0.20 % | 13.83 |
| CCNet5D (067) | 0.0145 | 0.16 % | 18.89 |
| profile NeRSI (067) | 0.0109 | 0.12 % | 12.56 |

**cINR は ReGSI の 3.7 倍、CCNet5D の 9.0 倍の偽振幅を作る。** 参照が厳密に無音なので
この差は曖昧さなく「作ってしまった信号」である。DRR が最大なのは、ランク縮小が窓外の信号を
窓内へにじませるためと整合する。

機構とも整合する。`models/trace_context_field.py` には時間シフト・moveout 補正が1つもなく、
ReGSI も `max_edge_time_shift_samples: 0` である。オフセットの違う近傍を時間シフトなしで重ねると、
最も近い近傍の初動より前にエネルギーが出る。FORGE の共有前処理にある 500 m/s の canvas alignment は
粗い線形 moveout であって初動整列ではないため、近傍間の差分 moveout はほぼ未補正で残る。

## 位置づけと留保

- **事後的・開示付きの副指標**である。study の採点結果を見た後に追加したので、選択には遡って使えない
  （選択は validation relMSE で確定済み）。主指標・順位・採否はどれも変更していない。
- 窓の定数は観測 trace から測った宣言値であり、初動 pick ではない。pick 版（凍結 pick を hash 固定）は
  別の感度解析になる。
- **絶対振幅の平均は近オフセット trace に支配される。** 結果2と結果3が別の順序を与えるのはそのためで、
  どちらか一方だけを引用しない。
- 偽振幅が「近傍オフセット差」に起因するという説明は機構と整合するが、**本測定は因果を検証していない**。
  検証には trace ごとの近傍オフセット差と偽振幅の対応を測る必要があり、別作業とする。
- 1 mask・1 model seed（shot50）／ seed 7321 のみ（共通 grid）の記述的測定で、CI も多重比較補正もない。
