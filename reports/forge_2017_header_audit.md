# FORGE 2017 全ファイルのヘッダー監査・トレース分類

[Study 047](../studies/study_047_forge_header_audit/README.md) の監査結果。
**ヘッダー上の地震波候補510,013本を抽出できた。波形品質と5D格子の成立性は未判定。**

## 範囲と成果物

ローカルの `data/external/forge_2017` にある全294 SEG-Yを対象とし、
全トレースの240バイトヘッダーと全ファイルの3,600バイトヘッダーを保存した。
付属するNavigation 2ファイル、ZIP、XLSも入力台帳とSHA-256の対象。
ZIP/XLSの内容解析、振幅・スペクトル解析、波形補正は実施していない。

配布元は `1-300c` を、全1,122ファイルのうち相関処理済み3Dショットギャザーの
1–300のアーカイブと説明している。
[Data.gov](https://catalog.data.gov/dataset/utah-forge-2d-and-3d-seismic-data)

1–8の意味は [SEG-Y Rev.0の定義](https://www.seg.org/wp-content/uploads/2025/11/seg_y_rev0.pdf) に基づく。

補助領域の一部と考えられるが、具体的な機器・成分の名前は付けていない。

全dead指定1,841本と補助・未確認コード1,764本は受振点座標がともにゼロ。
地震波候補のゼロ座標、サンプル数・間隔の不一致、Navigation座標不一致は0本。
1ショット当たりの地震波候補は1,731–1,737本。

## 測点IDとNavigation照合

以下はFORGEの実値、テキストヘッダーの100倍記録の宣言、Navigation、ファイル名の
照合に基づく対応である。メーカー仕様書による確定とは区別する。

| トレース内の1始まりバイト位置 | 解釈 | 保存値への操作 |
|---|---|---|
| 181–184 | 受振測線番号 | /100 |
| 185–188 | 受振測点番号 | /100 |
| 189–192 | 震源測線番号 | /100 |
| 193–196 | 震源測点番号 | /100 |

Rev.1のCDP座標、inline/crosslineというフィールド名は適用していない。
SP1はNAD83 / UTM Zone 12Nと宣言され、測点IDと0.1 m単位の座標を解釈した。

- 震源Navigationは1,114点。手元の全294震源を含み、収録座標精度でSEG-Yと一致。
- 受振点Navigationは272点。SEG-Yの全1,741受振点の一部に限られる。
- 地震波候補のうち79,060本は受振点Navigationと一致、430,953本はNavigation未掲載。
- 地震波候補の照合可能行での座標差最大値は震源・受振点とも0.0000 m。
- Navigationにある受振点でもdead行は座標がゼロであり、908行は座標照合不能として区別。

Navigation未掲載の地震波候補を欠測や異常とは扱わない。外部測量で検証できた範囲が
部分的であることを残し、SEG-Yヘッダー座標を維持する。

## 未解決事項と次の判断

1. **相関フラグの独自値**：全トレースで `correlated_raw=3`。
   Rev.0の1=no / 2=yesの解釈からは外れる。配布元のcorrelatedという由来は保持するが、
   この値から個別の処理内容を確定しない。
2. **sweep周波数の表記差**：テキストは4–84 Hz、トレースヘッダー原値は40/840。
   独自の倍率が考えられるものの未確定。40–840 Hzという取得帯域として扱わない。
3. **標準項目に見える独自値**：source datum原値は−2,147,352,576または131,072。
   物理的なdatum標高として解釈せず、rawのまま保持する。後半の未解釈領域も原バイト列を残した。
4. **成分・センサー・極性**：テキストには複数のgeophone構成と3C機器の記載があるが、
   code 1だけでは個々のトレースとの対応を確定できない。全510,013本が同じ成分・応答だとは主張しない。
5. **欠番と付属資料の範囲**：6 FFIDの不在理由、Navigationの収録範囲、XLS内の追加説明は未確認。

次は、候補トレースの震源・受振点配置図と観測有無の行列を作り、
空間4軸の広がり・格子間隔・不規則性を確認する。
並行して代表ギャザーの波形QCを行い、成分・応答の混在、dead指定以外の異常、
反射波を評価できる時間窓を確認してから比較用cropを固定する。
