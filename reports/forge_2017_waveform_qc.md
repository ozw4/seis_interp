# FORGE 2017 波形品質・成分確認

**全294ファイルの波形検査を完了した。ヘッダー候補の22本は全ゼロだった。
60 Hz付近の狭帯域波形とDC偏りもあり、数値的に読めることと反射波補間に適することは分けて判断する。**
成分は「各受振点1チャネル」まで確認できたが、Z/N/E、極性、機器応答は確定していない。

[Study 048](../studies/study_048_forge_waveform_qc/README.md) の結果。
波形runは `20260918T004702016430Z_5d660f87b9b4`、
成分根拠runは `20260918T005039397797Z_5d660f87b9b4_components`。

## 検査範囲と分類

全513,618トレースについて4,001サンプル・0–4 sを測定した。
元SEG-YのSHA-256を前回ヘッダー監査と照合し、振幅自体は変更していない。
下表の母集団はヘッダー候補510,013本。

| 判定 | 本数 | 候補内の割合 |
|---|---:|---:|
| 今回の数値チェック通過 | 496,922 | 97.4332% |
| 要確認フラグあり | 13,069 | 2.5625% |
| 全ゼロ | 22 | 0.0043% |
| NaN / Infを含む | 0 | 0% |
| 非ゼロの定数波形 | 0 | 0% |

全ゼロ22本は22ショット・17受振点に分散している。
ヘッダーdead指定1,841本もすべて全ゼロだったが、上表の候補には含まない。
標準補助・独自コード101–103は非ゼロの波形を持つが、地震波候補へは混ぜていない。
非有限値・定数波形を除いた候補は509,991本。

確認フラグは重複を許して以下を検出した。

| 診断 | 規則 | 本数 |
|---|---|---:|
| DC偏り | 絶対平均 / RMS > 0.1 | 12,809 |
| 振幅外れ値 | 同じショット・500 m offset帯の中央値に対するRMS比が100超または0.01未満 | 408 |
| 強い単発ピーク | 最大絶対値 / RMS > 20 | 0 |
| 平坦な極値 | 非ゼロの最大値または最小値が3サンプル以上連続 | 0 |

振幅外れ値は大振幅側255本、小振幅側153本。帯内の有効候補が20本未満なら判定しない。
これらの閾値は探索的なreview基準で、故障・飽和・ノイズの確定ではない。
相関処理後の極値検査で、取得時のクリッピングがなかったとは言えない。
`passed_numeric_checks` には、今回のフラグで拾わない周期ノイズ等が残り得る。

## 振幅と周波数

ヘッダー候補のRMS中央値は9.6397×10⁻⁵、99パーセンタイルは0.0114、最大は0.4942。
値はSEG-Y格納振幅であり、速度・変位・加速度などへの物理校正は未確認。
ショット・offset・受振点による差が大きく、共通の振幅スケールを決める前に外れ値の扱いが必要。

![全体QC](../runs/study_048_forge_waveform_qc/20260918T004702016430Z_5d660f87b9b4/figures/overview.png)

スペクトルは平均除去＋Hann窓の片側パワーで、509,991本を集計した。
各トレースを等重みにした場合、4–84 Hzの平均パワー割合は99.9730%。
同じ集計の5–95%累積パワー帯域は6.7483–32.2419 Hz、最大ピークは11.2472 Hz。
125 Hz以上の平均パワー割合は約6.0081×10⁻¹¹。
後続のダウンサンプリングを検討する材料にはなるが、今回は元の1 ms間隔を保持している。

取得論文には4–84 Hz、12 sのsweepとground roll・air blastの影響が記載される。
実測スペクトルの帯域はこの記述と整合する。ただし、帯域内パワーを反射波S/Nとは解釈しない。
[Miller et al., 2018, Acquisition and Processing](https://publications.mygeoenergynow.org/grc/1034095.pdf)

## 60 Hz付近の周期波形

エネルギー重み付き全体スペクトルの最大ピークは59.9850 Hz。
トレースごとのピーク周波数が59–61 Hzに入る候補は11,603本ある。
この本数だけで全例を電源ノイズと断定はしないが、狭帯域成分の影響は明瞭。

振幅比最大の例はFFID 181、元ファイルの0始まりtrace index 1574、受振点185/503。
同じショット・offset帯のRMS中央値の2,725.2638倍で、記録全体に周期波形が続く。
この例のHann窓パワーの99.9924%が59–61 Hzに集中する。
電源系干渉を疑う所見であり、発生源の確定ではない。

![振幅外れ値の原波形](../runs/study_048_forge_waveform_qc/20260918T004702016430Z_5d660f87b9b4/figures/review_181.png)

受振点185/503は197ショットで振幅reviewとなる。ほかに181/516で69ショットなど、
特定受振点に繰り返す問題があるため、トレース単位と受振点単位の両方で確認する。
一律notchや自動除外はまだ適用していない。

## ギャザーの目視確認

各震源測線で測点番号順の先頭・中央・末尾を選び、全5測線・15ショットの図を生成した。
各図は全候補トレースと、offset中央値が近・中・遠の受振測線断面を含む。
FFID 1、14、55、124、215、279を個別に目視確認し、全5震源測線を確認した。
表示はtrace RMSでのみ正規化し、フィルタ・AGC・静補正はしていない。

![代表ギャザーFFID124](../runs/study_048_forge_waveform_qc/20260918T004702016430Z_5d660f87b9b4/figures/gather_124.png)

- 測線内で連続するイベントが見える一方、近距離側には強い低周波波列があり、時間・offset依存が大きい。
- 表示上の垂直な弱振幅・空白列も存在する。例としてFFID 124には今回検出した全ゼロトレースが含まれる。
- 遠距離側のイベントは弱く、表示正規化を使っても反射波・直達/屈折波・表面波をこの段階で分離確定できない。
- 固定の単一時間窓をすべてのoffsetに採用する根拠はまだ不足している。

時間帯別RMSは0–0.5、0.5–1、1–2、2–4 sで保存した。
どの時間窓にも同じ評価価値があるわけではなく、次のgeometry EDAと合わせて
反射イベントの確認・offset制約を行ってから比較用cropを選ぶ。

## 成分・センサー確認の結論

**保存形式としては1震源・1受振点につき1地震波チャネル。
物理的なZ/N/E成分、極性の統一、センサー応答の統一は未確認。**

全294ファイルのテキストヘッダーに同じ記載がある。

- Vertical geophone: Ion SM-24（6×2、12×1）とOyo GS-32CT（6×1）
- 3C geophone: Ion SM-7

この一覧は測点への対応表ではなく、3Cの記載だけでこのデータがZ/N/E三成分組だとは言えない。
実際、ヘッダー候補の各震源・受振点組に複数成分のトレースはない。
成分特定を期待して独自bytes 209–212も調べたが、意味を裏付ける仕様は見つからず、
`32000000` / `33000000` / `34000000` のraw hexとして残した。
これらを成分・機種コードとは呼ばない。

取得論文は今回と一致する1,741受振点の反射法調査を説明しているが、
各記録チャネルの向き・機種への対応は確認できなかった。
[調査論文](https://publications.mygeoenergynow.org/grc/1034095.pdf)
別のFORGE nodal・微小地震監視データの三成分情報は流用していない。
追加のUGS報告・Phase 2B資料本体は今回のアクセスでタイムアウト／429となり、
成分根拠としては使っていない。ローカルXLSの内容解析は未実施。

最終的な物理成分の確定には、receiver/channel map、取得ログ、
または当該Hawk SEG-Y出力のメーカー仕様が必要。
現時点で論文・実験条件に書ける表現は「物理成分未確認の、各受振点1チャネルの相関済みショット記録」。

## 次の実験準備への判断

1. 全ゼロ22本は有効な補間targetに使わず、既存のdeadと分けてQC除外として記録する。
2. DC・振幅・60 Hz関連の問題は、受振点とoffset別に確認し、共通前処理か除外かを決める。
   前処理の有無で異なるbenchmarkを混ぜない。
3. 数値的に利用可能な509,991本を出発点にgeometry EDAを進める。
   これは最終評価用の正常トレース数ではない。
4. 成分統一は未確認のままなので、Z成分の比較と断定せず、取得仕様の確認事項として残す。
