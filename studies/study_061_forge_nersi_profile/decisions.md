# Decisions

## 2026-10-08 — NeRSIを原論文の断面単位で取り直す

**Status:** active

**Decision:**
study_060のNeRSIは、4つの実座標から1トレースを出す改変版（`NersiTrace`、study_052で導入）だった。
原論文（Gao et al., 2025）は規則格子にビニングしたデータを前提とし（V31 "regular 5D data interpolation"）、
実データも格子に平均化してから使っている（V36）。off-grid内挿は今後の課題と書かれている（V41）。
そこで、論文と同じ断面単位の `Nersi` を `nersi_profile` として追加し、study_060と同じ手順で探索・評価する。

断面は「震源セル×受振測線」で、受振点が列になる。入力は丸めない3座標とする。

- s_x, s_y: 震源の連続line・point座標
- r_x: 受振測線に属する受振点の連続line座標の平均

r_yにあたる受振点だけを格子の列に置く。
study_060の最終準備runでは、受振点の格子からのずれは最大3.4 m、受振測線内のline方向のずれは最大0.6 mだった。
格子から大きくずれているのは震源（最大116 m）で、震源は連続値のまま入力する。

ユーザー指示（2026-10-08）による設計で、study_060のtest結果（NeRSIが最下位）を見た後に決めた。
手法の中の設定は検証集合Vだけで選ぶが、この再実験をすること自体はtest結果を知った後の判断である。

**Evidence:**
- 論文: `data/geo-2023-0767.1.pdf`（V31・V36・V41）
- 幾何: `runs/study_060_forge_fair_grid/20260927T133829534335Z_25c5193588b2/features/real_geometry.parquet`

## 2026-10-08 — 1更新ちょうど64本と、断面単位の予算の揃え方

**Status:** active

**Decision:**
1更新ごとに、観測トレースを1本以上含む断面を無作為な順に引き、観測トレースが64本以上になった時点で止める。
引いた断面の観測トレースから、ちょうど64本を一様に選んでlossに使う。これはCCNet5Dの、パッチを重ねて
ちょうど64本を選ぶ規則と同じ形である。64本のどれかを含む断面だけをdecodeする。
学習率0.001・20,000更新・Adam・lossの定義・最終EMAはstudy_060のNeRSIと同じである。

中心設定はstudy_060のNeRSI中心設定のencoder幅150・decoder [16, 8, 4]・kernel 5・Fourier 16成分・
weight decay 5e-5・EMA 0.9998を保つ。これらはstudy_058・059でトレース単位版をマスクAのtestで選んだ値で、
独立に選んだ値ではない。latentは1チャネルとする。断面のlatentは543×4の格子なので、
decodeする出力1つあたりではトレース単位版の4チャネル×543と同じ大きさで、トレース1本あたりでは1/32になる。
パラメータ数は360,239で、帯域内である。
1更新でdecodeする量は断面約8枚分（約250トレース分）で、トレース単位版の64本分とFLOPsは揃っていない。

## 2026-10-08 — S1の軸・S2・対比の事前登録

**Status:** active

**Decision:**
トレース単位版のS1軸（midpoint・azimuthの周波数base）は極座標の入力に対する軸で、断面単位の座標には対応しない。
そこで、2つの座標群のFourier帯域を軸にする。

- 軸1: 震源座標（s_x, s_y）の帯域
- 軸2: 受振測線座標（r_x）の帯域

各軸の16番目の周波数を、その軸の番号格子のナイキストのq倍に置く（base = (q (n−1))^(1/16)）。
qは0.25・0.5・1とする。上側の延長はq = 2、下側の延長は周波数が増えないbase 1.00001
（study_060のazimuthの下側延長と同じ）とする。中点はqの中点（0.375・0.75）とする。
値はこのstudyのVとtestを見る前に決めた（study_060のVとtestの結果は既知）。

- 震源の下側延長は、q = 0.125だと震源lineのbaseが1を下回るため、周波数を増やさない値にした。
  実効的には震源pointの帯域を大きく下げ（q換算0.03）、震源lineはあまり変えない（q換算0.2）。
- r_xはこのsurveyでは格子番号とほぼ一致する（最大0.04 m）。q > 1では受振測線軸が折り返すため、
  軸2の上側延長は帯域を実質的に広げない。

これらの延長値と中点（grid.yamlの `fill:`）は、実験の実行指示を受けてアシスタントが決めたもので、
study_060のようにユーザーが個別に承認したものではない。

S2は、study_060の容量配分の2候補（latentを倍にして幅を減らす、decoderを倍にして幅を減らす）に対応する
l2w74とl1w123dec32、それにC3の再実装の既定値に合わせたdecoder kernel 3（k3）とする。
3候補ともFourier成分数とbaseを変えないので、S1の軸の意味（qの帯域）はS2の後も保たれる。
論文のC3実験のFourier成分数40は、同じbaseのままだと帯域も広がってS1の軸と交絡するため採らない。
S3のweight decayの水準と延長はstudy_060のNeRSIと同じである。

対比は、study_060の6手法すべてと `nersi_profile` の差の6つとし、Holm補正はこの6対比の中で行う。
差はすべて「nersi_profile − 他手法」で、負なら `nersi_profile` の誤差が小さい。
study_060の結果を見た後に決めた比較なので、roleはすべて `post_hoc_*` とし、study_060の事前登録の対比群とは別に扱う。
ReGSI-real以外の4手法は格子幾何で整列・学習しており、実座標の `nersi_profile` との差には幾何の違いも含まれる。
study_060の6手法の誤差は、study_060の最終評価runのseed平均誤差をそのまま使う。
そのtrace順とtest集合がこの評価と一致することをtest波形を読む前に、
非oracle復元のスケールが一致することを採点の前に確認する。

## 2026-10-08 — 原論文からの逸脱

**Status:** active

**Decision:**
断面単位の形・Fourier写像・2層のencoder・PixelShuffleの3段decoderは論文に従う。次の点は論文と異なる。

- nuclear norm正則化（論文の式11）は使わない。study_060の全ニューラル手法と同じlossと予算に揃えるためである。
  FORGEはノイズのある陸上の実データで、論文は実データでこの項を使っている。
- lossは、論文の観測位置の二乗誤差（式7）ではなく、ちょうど64本のトレースごとの相対MSE（study_060の共通loss）とする。
- Fourier成分数は16で、baseは格子のナイキストから決める（論文はC3でK = 40、実データでK = 80）。
- 時間軸は1 msから2 msへ間引いた2,001サンプルを500 m/sで整列した4,343サンプルのキャンバスで、
  decoderは4,344サンプルを出して最後の1サンプルを捨てる。
- 座標は論文のビン番号ではなく、震源の実座標（連続値）と受振測線の平均座標を使う。

## 2026-10-08 — 出力ほぼ0での停滞を、規則どおりそのまま採点する

**Status:** active

**Decision:**
探索20 runのうち4 runと最終3 runで、学習lossが最初から約1.0のまま下がらなかった（出力がほぼ0）。
lossは有限なので、grid.yamlの発散規則（非有限）にも、メモリ不足などの再実行規則にも当たらない。
study_060の手順にはこの停滞を再実行する規則がないため、事後に規則を足さず、記録された値をそのまま採点した。
study_060のトレース単位版でも、Rのseed 7302が同じように約1.0になっている。

同じseedでは設定が違っても同じloss曲線になり（Rのseed 7303の2 run）、停滞するかどうかはseedで決まっている。
学習の進んだseedと停滞したseedで、初期化時の出力RMSや中間活性の大きさに明確な差はなかった
（観測座標だけを使った確認で、V・testは読んでいない）。
したがって主指標1.0001は、断面単位NeRSIが学習できた場合の精度ではない。選択した設定で学習が進んだ2 seedのVは
0.9697と0.9698だった。study_060のトレース単位版の選択設定で学習が進んだ2 seedのVは0.8771と0.8899で
（3 seed平均0.9223はseed 7302の1.0を含む）、学習が進んだ場合どうしでも断面単位版のVのほうが大きい。

停滞を再実行する規則や別のseedで最終評価をやり直すことは、全手法に同じ規則を事前に決めない限り行わない。

**Status:** active

**Decision:**

C3のstudy_046で363,269パラメータに合わせた断面単位NeRSIの構成（Fourier 40成分、encoder 40、latent 28、

それ以外（20,000更新、学習率0.001、1更新ちょうど64本、loss、seed 7301）は本探索と同じにした。

選択目的の探索でだけ使え、パラメータ数の帯域検査だけを外す。更新数・学習率・lossトレース数の検査は残し、
manifestに `reference_only` を記録する。fair-gridの段階はこのrunを生成も参照もしない。
Vだけで採点し、testは読まない。本探索の選択と最終評価には使わない。

## 2026-10-08 — 構造を変えて帯域に収める参照実験

**Status:** active

**Decision:**
ユーザー指示により、パラメータ帯域を保ったまま、C3に近いlatentチャネル数を使える構造を参照実験として試す。
帯域を圧迫しているのはencoderの最終層（幅×latent×543×4）なので、latentの格子を小さくする2つの構造を選んだ。

- deep-time: `Nersi` に時間方向だけを2倍にする段（`NersiTimeBlock`、`time_upsample_channels`・`time_kernel_size`）を追加し、
  既存の3段の前に4段置く。NeRV・NeRSIの「小さな基底格子を段階的に拡大する」形を時間方向に延ばしたものである。
- rank-2 latent: 既存の `latent_spatial_rank` を使う。

どちらも事前登録したgridの外で、`reference_only` の探索として3 seedずつ実行し、Vだけで採点した。
本探索の選択・最終評価には使わない。学習条件（Fourier 40成分、weight decay 0、EMA 0.999）は
2,636,309パラメータの参照実験と揃え、構造だけを変えた。weight decayとEMAはこの構造向けに探索していない。

time-only段を加えた構成では、tunerの `resolved_config.yaml` の `profile_shape` は名目値（2008）のまま残る。
実際に使った形（4,352×32）は `final.pt` と `ema_*/final.pt` の `model_config` に記録される。
整列キャンバスのない準備runでも同じ形になるよう、`run_method` は整列なしの場合も時間側を同じ規則で揃える。

## 2026-10-08 — パラメータ数を変えない過学習対策（参照実験）

**Status:** active

**Decision:**
ユーザー指示により、deep-time構造（355,653パラメータ）の過学習対策を、パラメータを増やさない方法に限って試す。
学習lossは0.55まで下がる一方でVは約1.0で、global NMSEが1を超える（欠損位置に余分なエネルギーを出す）ため、
観測トレースへの過適合とみなした。

- 核ノルム（`training.nuclear_norm_weight`）: 論文の式11の低ランク正則化。復元断面ごとの核ノルムを
  `sqrt(時間×受振点)` で割り、断面の平均に重みを掛けてlossに足す。単位RMSのトレースからなる断面で、
  階数1なら1、最大で `sqrt(min(時間, 受振点))` になる。履歴の `loss` はデータ項だけを記録する。
- 座標ジッタ（`training.coordinate_jitter_cells`）: 学習で復元する断面の入力3座標に、各軸の格子1セルの指定倍以内の
  一様乱数を足す。ラベルは変えないので、隣接セルとの間で滑らかな写像を促す。0.5セルを上限にした（それを超えると
  隣のセルに入る）。乱数はトレース抽選と別の系列（seed, 1）で、抽選順は対策なしと同じになる。予測では使わない。
- weight decay: 既存の設定。

1 seedのふるい分けで最もVが小さかった座標ジッタ0.5と、それに最も効いた核ノルムの重み0.01を加えた組合せを、
3 seedで確認した。weight decayはこの構造で出力ほぼ0の停滞を起こしたため、組合せから外した。
いずれも事前登録外の参照実験で、Vだけで採点し、testは読んでいない。
