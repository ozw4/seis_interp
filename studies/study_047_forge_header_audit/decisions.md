# 分類・解釈の判断

## ヘッダー上の候補と波形品質を分ける

code 1を `seismic_candidate` とする。座標単位・scalar・座標の有無、
サンプル数・間隔、production指定、トレース番号、測点ID、重複、
Navigation照合、ファイル内の整合性を通った行を `header_eligible=true` とする。
これは波形QCの候補選択であり、反射波の有無、S/N、振幅、成分・極性を保証しない。

code 2/3はdead/dummy、4–8は標準で定義された補助チャネル、
その他は `unknown_code` として保持する。
[SEG-Y Rev.0](https://www.seg.org/wp-content/uploads/2025/11/seg_y_rev0.pdf)
では9以上はoptional useであり、101–103を特定の成分やセンサーへ割り当てない。
不採用行も削除せず、原ヘッダーと理由を残す。

## FORGE独自フィールド

テキストヘッダーはRev.0、little endian、IEEE floatと測線・測点番号の100倍記録を宣言する。
181/185/189/193バイト位置の整数を受振測線・受振測点・震源測線・震源測点の順とする
対応は、本データの数値をNavigationとファイル名に照合して得た推定。
メーカー仕様書に基づく確定とは区別する。
Rev.1のCDP座標・inline/crosslineとしては解釈しない。

SP1はこのデータ固有の固定幅・0.1 m単位として読み取る。
ヘッダー座標との一致を検証し、汎用SPS parserとはしない。
座標差の許容値はconfigに記録する。独立した0.1 m丸めを考慮するための値であり、
実データの一致を良くするために調整していない。

Navigation未掲載は座標不一致と区別する。未掲載だけでは候補から落とさず、
SEG-Yの座標を保持する。dead・補助行のゼロ座標をNavigationから補完しない。
再観測と思われる重複も自動で平均・間引きせず、確認待ちとして候補から外す。

## 独自メタデータの扱い

相関フラグ、sweep周波数、datumなどは標準通りの物理値として確定できないため原値を保存する。
配布元のcorrelated分類をデータ由来として記録し、フラグ3から処理履歴を独自推定しない。
XLSは入力台帳・ハッシュの対象とし、内容解析のために新しい依存関係を追加しない。
追加取得したZIPは全memberのCRCと展開先ファイルのSHA-256一致を検証する。
配布ファイルのDeflate64圧縮は既存のInfo-ZIP `unzip` で読み、新たなパッケージは追加しない。
この照合はローカルZIPと展開済みデータの整合性を示すもので、公開元の署名・チェックサムによる真正性確認ではない。
これらの解釈を変更する場合は、メーカー資料または取得・処理記録が必要。

## 全相関処理済みアーカイブへの入力拡張

前回の294ファイルから、追加812ファイルを含む1,106ファイルへ監査範囲を拡張する。
分類閾値は変更しない。FFID期待範囲は配布アーカイブの番号範囲に合わせる。
番号範囲内の欠番は展開漏れと同一視せず、ZIP内一覧とnavigation上の測点欠落を分けて報告する。
旧runと部分データのレポートは保持し、全体監査は新規runと別レポートへ保存する。
